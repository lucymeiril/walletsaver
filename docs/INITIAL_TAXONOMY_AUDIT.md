# 초기 통합 카테고리 분류 감사 (2026-09-03)

이 문서는 초기 분류 **초안**의 근거와 한계를 기록한다. DB 승인 또는 공개 승인 기록이 아니다. 실제 DB는 이 모듈에서 변경하지 않는다.

## 입력과 검토 범위

- 4사 검토 대기 원본 9,196개 관측을 읽기 전용으로 분류했다. 홈플러스 재수집 관측을 포함한 수치다.
- 첫 분류에서 제안된 2,279개 중복 제거 source listing의 상품명을 리프별 전체 목록으로 검토하고, 원본 경로와 충돌하는 사례를 보류 규칙에 반영했다.
- 원본 전체 상세 페이지를 재방문하거나 성분표를 확인한 것은 아니다. 미분류 4,000여 listing을 모두 수동 분류했다는 의미도 아니다.
- 생성 보고서는 Git 제외 경로 `.debug-artifacts/initial-taxonomy-review.json`에 있으며, 마트별 결과, 리프별 모든 상품명·원본 경로·URL, 미분류 경로별 목록을 포함한다.

## 분류 계약

- `UnifiedCategory`용 새 의미 기반 트리만 사용하며, 레거시 카테고리와 키워드를 읽지 않는다.
- 루트 포함 최대 4단계이고 모든 제안은 리프다. 내부 노드 또는 편의상 만든 `기타`에 상품을 밀어 넣지 않는다.
- 홈플러스 `attributes.mart_native_category_path`, 롯데마트 `attributes.category_path` 등의 전체 경로를 보존한다. 인접 중복 단계만 접는다.
- `/`, `ㆍ`, `·`는 한 원본 라벨 안의 구분 기호다. 특히 이마트의 `우유/유제품`을 계층 두 단계로 해석하지 않는다.
- 홈플러스 루트 공용 원본 ID나 누락된 롯데 ID 대신, 마트와 정규화된 전체 원본 경로로 안정적인 매핑 키를 만든다. 기존 원본 ID도 별도 보존한다.
- 알려진 말단 라벨과 상위/루트 문맥이 맞는 경로만 0.97의 분류 제안을 만든다. 원본 경로도 오염될 수 있으므로 제품명 유형 확인과 충돌 보류가 추가 적용된다.
- `Best`, `Obanjang`, `SpecialPriceOffers` 등 행사 표면은 카테고리가 아니다. 별도 명확한 상품명이나 공식 URL 유형 근거가 없으면 보류한다.
- 코스트코 공식 호스트의 알려진 URL **카테고리** 구간만 사용한다. 마지막 상품명 slug, 외부 호스트, 넓은 검색어는 리프 근거가 아니다. URL과 상품명 근거가 충돌하면 보류한다.
- 일반 상품명·키워드 근거는 2자 이상 완전 토큰/토큰열이다. `초코우유맛과자` 안의 `초코우유` 같은 임의 부분 문자열은 매칭하지 않는다. 아래 유제품 보강은 별도의 좁은 문맥 기반 규칙이며, 검색 키워드를 부분문자열 규칙으로 바꾸지 않는다.
- 키워드는 새 리프에만 연결되고 정규화된 동의어가 서로 다른 리프를 가리키면 생성이 실패한다.
- `review_status=classified`는 제안 상태이며, `approved`를 뜻하지 않는다.

## 남은 검토

- 이마트 상위 라벨만 있는 대부분의 행과 코스트코 넓은 URL/검색어는 여전히 보류다. 이를 채우기 위한 추측용 범용 리프를 추가하지 않았다.
- 코스트코 URL 자체도 완전하지 않다. `CandyGum`에 육포·어포, `Chocolates-Bars`에 젤리·팝콘, `Whole-BeansGround-Coffee`에 인스턴트 커피가 관측되어 URL 전면 자동 매핑은 부적절하다.
- 일부 마트의 스낵 원료별 분류나 세부 치즈 형태는 제목만으로 완전히 증명하기 어렵다. 분류 제안을 공개 승인으로 취급하지 말고, 실제 상품/포장 확인 또는 더 넓고 의미적으로 명확한 분류표 검토가 필요하다.
- 추가 분류는 신규 근거를 테스트와 함께 반영하거나, 검토자가 명시적인 listing별 결정을 제공하는 방식으로 진행한다.

최초 검증: `packages/db-admin/backend/tests/test_initial_taxonomy.py`의 61개 결정적 테스트가 통과했다. 라이브 사이트 수집이나 DB 적재는 이 테스트에 포함되지 않는다.

### 좁은 규칙과 의도적인 보류

- `contextual_dairy_title`은 0.90의 제안 근거다. 이마트·홈플러스·롯데의 호환 유제품 경로 또는 코스트코 공식 상품 URL의 호환 식품 문맥과 구체적인 제품형태를 모두 요구한다. 코스트코의 `우유` 검색어만으로는 작동하지 않는다.
- 코스트코 URL도 리프를 단독으로 결정하지 않는다. `Instant-FoodDumplingTraditional-PancakesCheese`는 만두·피자·조리식품이 섞인 식품 문맥일 뿐이다. `KimchiSide-Dishes`, 과자·빵·소스·건강보조식품·반려동물·가전 URL은 유제품 이름과 충돌하면 보류한다. 여러 공식 URL 중 하나라도 충돌하면 보류한다.
- 새 실제 타입 리프는 크림치즈, 생모짜렐라, 리코타, 부라타, 마스카르포네, 브리, 까망베르, 경성숙성치즈, 생크림, 아몬드음료, 말차우유다. 형태가 명시된 슬라이스·슈레드는 치즈 원료 품종보다 우선한다. `체다치즈`, `구워먹는치즈`, `치즈큐빅`, `스프레더블치즈`를 성분 확인 없이 가공치즈나 크림치즈로 밀어 넣지 않았다.
- `서울우유`, `연세우유`, `매일우유` 제조사명은 흰우유의 증거가 아니다. `할리스 바닐라딜라이트`, 카페라떼·콜드브루 등은 우유로 배정하지 않는다. `말차라떼 멸균우유`는 실제 우유 유형 명칭까지 있는 경우다. 지방·멸균 속성은 기존처럼 맛과 별도로 보존한다.
- `윌`, `쿠퍼스`, `메치니코프`, `비요뜨`, `짜요짜요`, `나100%`, `오트몬드` 등은 검증되지 않은 상품군 alias로 추측하지 않았다. 일반 `요거트`가 g 또는 ml로 팔린다는 이유만으로 떠먹는/마시는 형태를 확정하지 않았다.
