# GLOSSARY.md — 도메인 용어 사전

> **이 문서의 목적**: AI가 도메인 용어를 혼동 없이 이해하고, 정확한 코드를 작성하도록.
> 식품 가격 비교 서비스에 특화된 용어와 코드에서의 매핑을 정의한다.

---

## 1. 프로젝트 용어

| 용어 | 영문 | 설명 | 코드 매핑 |
|------|------|------|-----------|

| 가격 오염 | Price Pollution | 핫딜 등 비정상 가격이 평균에 포함되는 것. 절대 금지 | — |
| 가격 등급 | Price Tier | 현재가 vs 평균가 비율로 판정 (ultra/great/good/wait) | `PriceTier` 모델 |
| 전략 캐스케이드 | Strategy Cascade | 가벼운 전략부터 시도 → 실패 시 다음 전략 | `StrategyExecutor` |
| 플러그인 크롤러 | Plugin Crawler | `CrawlerContract` 구현체. 폴더 추가로 등록 | `crawlers/` |
| 진단 리포트 | Diagnosis Report | 크롤링 실패 원인 자동 분류 + 대응 추천 | `DiagnosisReport` |
| 속성 태그 | Product Attribute | 같은 품목도 속성에 따라 가격이 다름을 표현 | `ProductAttribute` |
| 이벤트 버스 | Event Bus | 모듈 간 느슨한 결합을 위한 pub/sub 시스템 | `EventBus` |

## 4. 축산물 분류

### 4.1 한우 등급제

| 등급 | 설명 | 가격 수준 |
|------|------|-----------|
| 1++ (투쁠) | 최상위 마블링 | 가장 비쌈 |
| 1+ (원쁠) | 상위 마블링 | 비쌈 |
| 1등급 | 양호한 마블링 | 보통~비쌈 |
| 2등급 | 일반 | 보통 |
| 3등급 | 하위 | 저렴 |

> **코드에서**: `AttrKeys.GRADE`, `GRADE_VALUES = ["1++", "1+", "1등급", "2등급", "3등급", ...]`

### 4.2 보관 방식 (가격 영향 극대)

| 보관 | 설명 | 가격 영향 |
|------|------|-----------|
| 냉장 | 0~10°C 보관, 신선 | 가장 비쌈 (냉동의 2~5배) |
| 냉동 | -18°C 이하, 장기보관 | 상대적 저렴 |
| 실온 | 상온 보관 가능 | 품목에 따라 다름 |
| 생물 | 살아있는 상태 (활어 등) | 매우 비쌈 |

> **코드에서**: `AttrKeys.STORAGE`, `STORAGE_VALUES = ["냉동", "냉장", "실온", "생물"]`
> **핵심**: 냉동 삼겹살과 냉장 삼겹살을 같은 품목으로 비교하면 안 됨!

### 4.3 원산지

| 코드 | 설명 | 가격 영향 (돼지고기 기준) |
|------|------|--------------------------|
| 국산 | 한국산 | 가장 비쌈 |
| 미국 | 수입산 | 국산의 40~60% |
| 호주 | 수입산 | 국산의 50~70% |
| 스페인 | 이베리코 등 | 프리미엄은 국산보다 비쌈 |
| 캐나다 | 수입산 | 국산의 40~60% |

> **코드에서**: `AttrKeys.ORIGIN`, `ORIGIN_VALUES = ["국산", "미국", "호주", ...]`

### 4.4 인증 표시

| 인증 | 설명 | 가격 영향 |
|------|------|-----------|
| 동물복지 | 동물복지 인증 축산물 | +20~50% |
| 무항생제 | 항생제 미사용 | +10~30% |
| 유기농 | 유기농 인증 | +30~100% |
| HACCP | 식품안전관리인증 | 표준 (대부분 보유) |
| GAP | 우수농산물관리인증 | 농산물 기준 |
| 친환경 | 친환경 인증 | +10~30% |

> **코드에서**: `AttrKeys.CERT`, `CERT_VALUES = ["동물복지", "무항생제", "유기농", ...]`

## 5. KAMIS 카테고리 체계

KAMIS의 분류를 기반으로 프로젝트 카테고리 트리를 구성:

```
전체
├── 채소류
│   ├── 엽경채류 (배추, 양배추, 시금치)
│   ├── 근채류 (양파, 감자, 당근)
│   ├── 과채류 (토마토, 오이, 고추)
│   └── 조미채소 (대파, 마늘, 생강)
├── 과일류 (사과, 배, 감귤, 포도, 딸기, 바나나, 수박)
├── 축산물
│   ├── 돼지고기 (삼겹살, 앞다리, 목살, 갈비)
│   ├── 소고기 (등심, 갈비살, 안심)
│   ├── 닭고기 (가슴살, 통닭)
│   └── 란류 (계란)
├── 수산물
│   ├── 생선류 (고등어, 갈치, 명태)
│   ├── 갑각류 (새우, 킹크랩)
│   └── 패류 (홍합, 조개)
├── 곡류 (쌀, 보리, 잡곡)
├── 유제품 (우유, 요거트, 치즈, 버터)
├── 가공식품 (라면, 국수, 즉석밥, 통조림, 두부, 만두, 냉동식품)
├── 조미료
│   ├── 유지류 (식용유)
│   └── 장류 (간장, 된장, 고추장)
└── 음료 (탄산음료, 주스, 커피, 생수)
```

> **코드에서**: `core/categories.py` → `build_default_tree()`

## 8. 크롤링 전략 난이도

| 난이도 | 전략명 | 영문 코드 | 설명 |
|--------|--------|-----------|------|

## 9. 통계 용어

| 용어 | 영문 | 설명 | 코드에서 |
|------|------|------|----------|
| IQR | Interquartile Range | 사분위 범위, 이상치 제거에 사용 | `remove_outliers_iqr()` |
| SMA | Simple Moving Average | 단순 이동평균 (7일, 30일) | `simple_moving_average()` |
| EMA | Exponential Moving Average | 지수 이동평균 (최근 가격 가중) | `exponential_moving_average()` |
| 신뢰구간 | Confidence Interval | 평균 ± 2σ | `PriceStats.confidence_low/high` |
| 이상치 | Outlier | IQR 방식으로 제거되는 극단값 | `PriceStats.outliers_removed` |
| 계절성 | Seasonality | 전년 동기 대비 가격 변동 | `seasonal_comparison()` |

## 10. 에러 타입 한국어 매핑

| ErrorType | 한국어 | 대응 |
|-----------|--------|------|
| `http_error` | HTTP 응답 에러 | URL 확인, 서버 점검 대기 |
| `captcha_detected` | 캡챠 감지 | 요청 간격 늘리기, 프록시 교체 |
| `ip_banned` | IP 차단 | 프록시 교체, UA 변경 |
| `js_challenge` | JS 챌린지 | 브라우저 전략 사용 |
| `dom_changed` | DOM 구조 변경 | CSS 셀렉터 업데이트 |
| `timeout` | 시간 초과 | 타임아웃 값 증가 |
| `login_required` | 로그인 필요 | 인증 설정 |
| `empty_response` | 빈 응답 | JS 렌더링 대기 |
| `parse_error` | 파싱 오류 | 파싱 로직 점검 |
| `network_error` | 네트워크 오류 | 연결 확인 |
| `unknown` | 알 수 없음 | 로그 확인 |
