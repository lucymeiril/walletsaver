# 개발일지 규약

이 디렉터리는 **세션 종료 시 남기는 한국어 개발일지**를 보관한다.  
미래의 AI 에이전트와 사람이 "무엇을 왜 했는지" 빠르게 이해하도록 돕는 것이 목적이다.

## 작성 원칙

- 한국어로 쓴다.
- 블로그 글처럼 흐름이 보이게 쓴다.
- 단순 완료 보고가 아니라 판단과 맥락을 남긴다.

## 꼭 포함할 내용

```text
- 오늘 목표
- 실제 작업 순서
- 사용한 데이터/근거
- 결과 수치 또는 확인 내용
- 막힌 지점
- 다음 세션 추천 작업
```

## 파일명 예시

```text
2026-05-16-agent-workflow.md
2026-05-16-phaseA-crawler-audit.md
```
