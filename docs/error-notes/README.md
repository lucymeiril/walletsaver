# 오류 노트 규약

이 디렉터리는 **실패, 오류, 재현 방법, 해결 과정**을 다음 AI가 바로 이어받을 수 있게 정리하는 장소다.

## 작성 원칙

- 실패를 숨기지 않는다.
- "안 됨"으로 끝내지 않고 원인과 해결 또는 미해결 상태를 적는다.
- 한국어로, 비개발자도 흐름을 따라갈 수 있게 쓴다.

## 꼭 포함할 내용

```text
- 어디서 실패했는지
- 어떤 입력/환경에서 발생했는지
- 오류 메시지 또는 실제 증상
- 원인 분석
- 해결 방법
- 아직 미해결이면 현재 블로커와 다음 시도
```

## 파일명 예시

```text
2026-05-16-homeplus-threshold-audit.md
2026-05-16-lottemart-waf-handoff.md
```
