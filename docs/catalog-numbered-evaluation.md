- 기존 보류 계약은 번호 도구가 자동 수집하지 않는다. 과일 가변 중량 계약을 늦게 발견해 pass99가 테스트 단계에서 실패했다. 로그를 보존했고 새 pass100으로 인증했다. 다음 후보 선택 때 해당 선반의 기존 테스트를 먼저 검색한다.

- 판단 자체가 필요한 애매한 상품, 새 리프 설계, 기존 충돌 계약 확인은 자동화되지 않았다. 전체 재구축 비용도 유지한다.

결론: 반복적인 출력·필드 작성에는 유용하고 기존 검사도 실제 오류를 잡았다. 분류 판단 속도나 전체 토큰 절감률까지 입증한 것은 아니다.
