## 🎯 목표

사용자가 실제로 활용할 수 있도록 기존 기능 강화:
1. 마트 상품 상세 모달 + SSG/공식 링크
2. 동네 물가 지도 가격 표시 + 상세 모달 + 지도 연동
3. 마트 전단지 크롤링 & 뷰어
4. DB 관리 상품 등록 자동완성 UX

## 📋 구현 내용

### 1. 마트 상품 상세 모달 (`feat(mart)`)
- **MartPage.jsx**: 상품 클릭 시 상세 모달 표시
  - 상품 이미지 + 할인율 배지 오버레이
  - 판매가/정가/할인율/이벤트/단위/매장 정보
  - **"상품 페이지로 이동"** 버튼 — SSG/마트 공식 페이지 새 탭 열기
  - "장보기 리스트에 추가" 기능
  - DB 상품 매칭 시 평균가 대비 분석
- **db.py**: `_save_discount_items` — `image_url`, `event_name`, `unit`, `category`를 `raw_data` JSON에 저장
- **mock_responses.py**: 모든 마트 항목에 `detail_url`, `unit`, `store` 필드 추가

### 2. 동네 물가 지도 강화 (`feat(LocalPage)`)
- **가격 표시**: 네이버 검색 결과에 평균가/최저~최고가 범위 표시
- **NaverPlaceDetailContent**: 가게 상세 모달
  - 이미지, 카테고리 배지, 주소, 전화번호
  - 가격 요약 바 (평균/최저/최고)
  - 전체 메뉴 테이블
  - "🗺️ 지도에서 위치 보기" — iframe 지도에서 해당 가게 포커스
  - "네이버 지도에서 보기" 외부 링크
- **지도 연동**: 모달에서 버튼 클릭 시 iframe이 해당 가게로 검색, "↩️ 기본 지도로 돌아가기" 리셋
- 주유소/식당 모달에도 지도 포커스 버튼 추가

### 3. 마트 전단지 API & 뷰어 (`feat(marts)`)
- **flyer_service.py**: 전단지 서비스
  - 마트 4사 공식 전단지 URL 관리 (이마트 SSG, 홈플러스, 롯데마트, 코스트코)
  - 이마트 전단지 이미지 스크래핑 (CDN 패턴, leaflet/event 이미지 감지)
  - 6시간 인메모리 캐시, 목~수 자동 기간 계산
  - 스크래핑 실패 시 웹 URL 폴백
- **marts.py**: `GET /api/marts/flyers`, `GET /api/marts/{store}/flyers` 엔드포인트
- **MartPage.jsx 전단지 탭**:
  - 마트 탭 선택기 (이마트/홈플러스/롯데마트/코스트코)
  - 이미지 캐러셀 (페이지 넘기기, 확대, 페이지 인디케이터)
  - 로딩/에러 상태 처리 + 재시도
  - 이미지 없을 시 공식 사이트 링크 카드
  - 하단 마트별 바로가기 퀵 링크

### 4. DB 관리 상품 UX (`feat(db-admin)`)
- **SearchableSelect.jsx**: 카테고리 드롭다운
  - 계층형 카테고리를 "농축산물 > 육류 > 소고기" 경로 라벨로 평탄화
  - 실시간 필터링 + 키보드 내비게이션 (↑↓ Enter Esc)
  - 선택 항목 칩 표시
  - **"+ 새 카테고리"** 인라인 생성 (부모 선택 가능)
- **TagInput.jsx**: 키워드 멀티 셀렉트
  - 200ms 디바운스 검색 (`/api/keywords/search`)
  - 태그 칩 표시 + 삭제, Backspace로 마지막 태그 제거
  - **"+ 새 키워드"** Enter로 즉시 생성
- **Products.jsx**: 두 컴포넌트 통합
  - 일반 텍스트 입력 → SearchableSelect/TagInput 교체
  - 상품 저장 시 키워드-카테고리 자동 연결

## 💡 설계 결정

1. **전단지 이미지 스크래핑**: SSG는 SPA라 정적 스크래핑에 한계. CDN 패턴 매칭으로 시도하되, 실패 시 공식 페이지 링크로 폴백. 향후 Playwright 기반 스크래핑으로 강화 가능.

2. **메뉴 가격 파싱**: `menu_info`가 배열 또는 문자열로 오는 두 가지 형식 모두 지원. 가격 범위 (최저~최고) + 평균 계산으로 대표 가격 표시.

3. **인라인 생성 패턴**: SearchableSelect/TagInput 모두 드롭다운 내에서 바로 새 항목 생성 가능 → 화면 전환 없이 데이터 등록 (사용 편의성 극대화).
