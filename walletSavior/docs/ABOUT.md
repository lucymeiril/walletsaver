# 🛡️ 지갑 지키미 (WalletSavior)

**정부 공공데이터 기반 가격 비교·핫딜 검증 서비스**

> "이 할인, 진짜 싼 건가요?" — 데이터로 답해드려요.

---

## 📌 프로젝트 소개

지갑 지키미는 대한민국 소비자를 위한 **통합 가격 비교 플랫폼**이에요.

정부 공공데이터(KAMIS, KOSIS, OPINET)를 기준 가격으로 활용해서,
마트 세일, 핫딜 커뮤니티, 배달앱, 주유소 등 흩어진 가격 정보를
**한곳에서 비교하고 검증**할 수 있어요.

"감"이 아닌 "데이터"로 현명한 소비를 도와주는 서비스입니다.

---

## ✨ 핵심 기능

- 🏷️ **가격 티어 시스템** — 적정가 대비 자동 판정 (🔥울트라 핫딜 ~ ⏳기다려)
- 📊 **가격 추이 차트** — 30/90/365일 가격 변동 시각화
- 🏬 **마트 3사 비교** — 이마트, 홈플러스, 롯데마트 세일 정보 통합
- ⛽ **주변 최저가** — 위치 기반 주유소·식당 가격 비교
- 🍳 **직접 해먹기 계산기** — 재료비 vs 식당 vs 배달 비용 비교
- 💬 **커뮤니티** — 핫딜 공유 + DB 자동 가격 검증 + 투표
- 🧩 **플러그인 시스템** — 알림, 테마 등 사용자 맞춤 기능
- 📈 **고인물 모드** — 상세 통계·원데이터·계절성 분석

## 💡 가격 산정 방식

### 적정가 (Baseline Price)

지갑 지키미의 핵심인 **적정가**는 다음 데이터로 산출돼요:

1. **정부 공공데이터** — KAMIS(농산물 도매가), KOSIS(소비자물가), OPINET(유가)
2. **대형마트 공식 가격** — 이마트, 홈플러스, 롯데마트의 정상가

### 가격 오염 방지

| 데이터 유형 | 적정가 산출 포함 여부 | 이유 |
|------------|:---:|------|
| 정부 공공데이터 | ✅ | 가장 신뢰할 수 있는 공식 데이터 |
| 대형마트 정상가 | ✅ | 일반 소비자 기준 가격 |
| 마트 할인가 | ❌ | 일시적 가격, 평균 왜곡 가능 |
| 커뮤니티 핫딜 가격 | ❌ | 바이럴·허위 가격 혼입 위험 |

> **핵심 원칙**: 핫딜 가격은 적정가 산출에 절대 포함하지 않아요.
> 이를 통해 바이럴 마케팅이나 허위 가격이 기준을 오염시키는 것을 방지해요.

### 통계 처리

- **IQR 방식**으로 이상치 제거 (극단적인 가격 자동 필터링)
- **이동평균** (7일/30일 SMA, EMA) 적용
- **계절성 반영** — 전년 동기 대비 가격 비교

### 가격 티어 판정

| 티어 | 조건 | 의미 |
|------|------|------|
| 🔥 울트라 핫딜 | ≤ 적정가의 70% | 역대급 가격 |
| 💰 대박 핫딜 | 70~85% | 매우 좋은 가격 |
| 👍 괜찮은 가격 | 85~105% | 적정 수준 |
| ⏳ 기다려 | > 105% | 현재 비싼 편 |

## 📐 개발 원칙

### 🧪 TDD (테스트 주도 개발)
- 모든 기능은 테스트를 먼저 작성하고 구현해요
- 현재 64개 이상의 테스트 케이스 운영 중

### 📦 모듈화
- 엄격한 모듈 분리 — 모든 모듈은 `core/`에만 의존
- 모듈 간 직접 의존성 제로
- 이벤트 기반 통신 (EventBus)

### 🧩 플러그인 아키텍처
- 새로운 데이터 소스 추가 시 기존 코드 수정 불필요
- `plugin.yaml` 기반 자동 등록
- 사용자 플러그인도 샌드박스 환경에서 안전하게 실행
