# DB 관리자 종합 개선 기획서

## 1. 카테고리-키워드 통합 관리

### 1.1 문제점
- 카테고리, 키워드, 상품을 **3개 탭에서 각각 따로 등록**해야 함
- 카테고리 등록 → 키워드 등록 → 상품 등록 순서 강제
- 키워드 등록 시 카테고리 ID를 외워야 함 (자동완성 없음)

### 1.2 통합 관리 UI

#### A. 카테고리-키워드 통합 탭
기존 카테고리 탭과 키워드 탭을 **하나의 "분류 관리" 탭**으로 통합.

**레이아웃:**
```
┌─────────────────────────────────────────────────────┐
│ [분류 관리]                                          │
│                                                     │
│  좌측: 카테고리 트리 (접기/펼치기)                      │
│  ├─ 축산물                                          │
│  │  ├─ 돼지고기                                     │
│  │  │  ├─ 삼겹살 (키워드: 삼겹살, 오겹살, 대패삼겹)      │
│  │  │  ├─ 목살 (키워드: 목살, 목심)                    │
│  │  │  └─ [+ 하위 카테고리/키워드 추가]                 │
│  │  └─ 소고기                                       │
│  └─ [+ 대분류 추가]                                  │
│                                                     │
│  우측: 선택된 카테고리 상세                              │
│  ┌─ 카테고리 정보 ─────────────────────────┐         │
│  │ ID: livestock.pork.belly               │         │
│  │ 이름: 삼겹살  아이콘: 🥓               │         │
│  │ 상품 수: 12개  키워드 수: 3개           │         │
│  └───────────────────────────────────────┘         │
│  ┌─ 연결된 키워드 ─────────────────────────┐         │
│  │ 삼겹살 (검색 106회) [동의어: 오겹살, 대패]│         │
│  │ 돼지고기 (검색 111회) [동의어: 돈육]      │         │
│  │ [+ 키워드 추가] (자동완성 포함)          │         │
│  └───────────────────────────────────────┘         │
│  ┌─ 해당 카테고리 상품 목록 (축약) ──────────┐         │
│  │ 한돈 삼겹살 100G | 이마트 | 2,200원      │         │
│  │ 보먹돼 삼겹살 1kg | 롯데마트 | 10,098원   │         │
│  └───────────────────────────────────────┘         │
└─────────────────────────────────────────────────────┘
```

**핵심 기능:**
- 트리에서 카테고리 클릭 → 우측에 키워드+상품 동시 표시
- 키워드 추가 시 카테고리 자동 연결 (현재 선택된 카테고리)
- 카테고리 추가 시 기본 키워드 자동 생성 제안
- 드래그앤드롭으로 카테고리 이동
- 인라인 편집 (더블클릭)

#### B. 상품 등록 마법사
상품 등록 시 단계별 안내:
1. **상품명 입력** → 자동분류 엔진이 카테고리 추천
2. **카테고리 확인/변경** → 트리에서 선택 또는 추천 수락
3. **키워드 자동 연결** → 관련 키워드 자동 체크, 추가 가능
4. **가격/단위 입력** → 완료

## 3. 일괄 삭제 & DB 리셋

### 3.1 현재 상태
- 개별 삭제, 선택 삭제 가능
- **전체 삭제/리셋 기능 없음**

### 3.2 추가 기능

#### A. 소스별 일괄 삭제
```
[이마트 데이터 전체 삭제] [홈플러스 데이터 전체 삭제] ...
```
- 해당 소스의 DiscountHistory + Product 일괄 삭제
- 확인 모달: "이마트 상품 44개와 할인이력 128건을 삭제합니다. 정말 삭제하시겠습니까?"
- 입력 확인: 소스 이름 직접 타이핑해야 삭제 가능 (실수 방지)

#### B. DB 초기화
```
[데이터베이스 초기화] → 모든 상품/가격/이력 삭제, 카테고리/키워드 유지
[완전 초기화] → 시드 데이터로 리셋 (카테고리/키워드 포함)
```
- 매우 위험한 작업 → 2단계 확인 + 백업 자동 생성

#### C. 백엔드 API
```
POST /admin/reset-source    { source: "emart" }
POST /admin/reset-data      { keep_categories: true }
POST /admin/reset-all       { confirm: "RESET_ALL" }
```

## 4. 날짜 관리 & 아카이브 시스템

### 4.1 날짜 가시성 개선

#### A. 상품 테이블에 날짜 컬럼 추가
```
이름 | 카테고리 | 가격 | 할인율 | 소스 | 크롤링일 | 할인기간 | 상태
삼겹살 | 돼지고기 | 2,200 | 49% | 이마트 | 2시간 전 | 4/1~4/7 | 🟢 진행중
목심   | 돼지고기 | 6,059 | 30% | 롯데  | 3일 전   | 3/25~3/31| 🔴 만료
```

**상태 배지:**
- 🟢 진행중 (valid_to > now 또는 valid_to 없음 & crawled_at < 7일)
- 🟡 곧 만료 (valid_to - now < 24시간)
- 🔴 만료 (valid_to < now)
- ⚪ 기간 불명 (valid_from/to 없음 & crawled_at > 7일)

**상대 시간 표시:**
- "2시간 전", "3일 전", "1주 전" 등 상대 시간
- 호버 시 정확한 날짜/시간 툴팁

#### B. 날짜 기반 필터
```
[전체] [진행중] [곧 만료] [만료됨] | 기간: [시작일] ~ [종료일]
```

### 4.2 아카이브 시스템

#### A. 아카이브 테이블
```python
class ArchivedDiscount(Base):
    __tablename__ = 'archived_discounts'
    id = Column(Integer, primary_key=True)
    product_name = Column(String, nullable=False)
    category_id = Column(String)
    price = Column(Float)
    original_price = Column(Float)
    source = Column(String)
    crawled_at = Column(DateTime)
    valid_from = Column(DateTime)
    valid_to = Column(DateTime)
    archived_at = Column(DateTime, default=datetime.utcnow)
    archive_reason = Column(String)  # "expired", "cleanup", "manual"
```

#### B. 아카이브 워크플로우
1. **자동 아카이브**: 매일 스케줄러 → valid_to 지난 항목 → 아카이브 이동
2. **수동 아카이브**: 관리자가 선택 → "아카이브로 이동" 버튼
3. **통계 활용**: 아카이브 데이터로 장기 가격 추이, 시즌별 할인 패턴 분석

#### C. 아카이브 뷰
- 별도 "아카이브" 탭 또는 Analytics 하위
- 검색/필터 가능
- 통계 차트: 월별 평균가 추이, 소스별 할인 빈도

## 5. 분석(Analytics) 강화

### 5.1 현재 → 추가할 차트/기능

| 현재 | 추가 |
|------|------|
| 가격 추이 비교 (5개) | 카테고리별 가격 분포 히트맵 |
| 소스 통계 | 소스별 할인율 비교 차트 |
| 카테고리 평균가 | 시간대별 크롤링 성공률 |
| 최근 수집 내역 | 이상치 분포도 + CRUD |
| - | 가격 변동 알림 설정 |
| - | 카테고리별 상품 수 트리맵 |
| - | 월별/주별 할인 트렌드 |

### 5.2 이상치 관리 CRUD

**현재:** 조회 + 화이트리스트만 가능
**개선:**
```
[이상치 목록]
| 상품 | 가격 | 평균 | 편차 | 날짜 | 조작 |
| 삼겹살 | 500원 | 2,200원 | -77% | 4/1 | [수정] [삭제] [화이트리스트] [무시] |
```

- **수정**: 가격 직접 수정 (오타 교정)
- **삭제**: 해당 가격 이력 제거
- **화이트리스트**: 정상 가격으로 인정 (기존)
- **무시**: 통계에서 제외하되 이력은 보존

### 5.3 데이터 내보내기
- CSV/JSON 다운로드 (선택 범위)
- 차트 이미지 PNG 저장
- 보고서 생성 (기간별 요약)

## 7. 테스트 시나리오

1. 카테고리 트리에서 노드 클릭 → 키워드+상품 동시 로드
2. 카테고리에 키워드 인라인 추가 → DB 반영 확인
3. 상품 등록 마법사 → 자동분류 → 카테고리 추천 → 키워드 연결
4. 소스별 일괄 삭제 → 확인 모달 → 삭제 확인
5. 만료 상품 자동 감지 → 상태 배지 표시
6. 아카이브 이동 → 원본 삭제 → 아카이브에서 조회
7. 이상치 수정/삭제 → 통계 재계산
8. ShoppingItem(지오다노) → Products 탭에서 조회
