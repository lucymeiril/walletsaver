# G0 정찰 — 홈플러스 (mfront.homeplus.co.kr)

## 핵심 발견 (기존 크롤러 가정과의 차이)
- 사용자가 말한 `delivery=HYPER_DRCT` 같은 URL 파라미터는 **카테고리 진입 URL에는 없음**. 대신 `storeType=HYPER`/`EXP`가 **상품 URL 쿼리**에 박힘.
- 카테고리/리스트 페이지는 일반적인 SSR/CSR 혼합. `__NEXT_DATA__` 같은 단일 직렬화 페이로드 없이 사이드바 필터로 필터링.
- **사이트 footer 공식 명시**: "사이트 내에는 홈플러스㈜에 입점한 개별판매자가 판매하는 상품이 포함되어 있습니다." → 외부 입점 셀러 존재 공식 확인.

## URL 패턴 / 안정 식별자
- 카테고리 리스트: `/list?categoryDepth=<0~N>&categoryId=<n>` — `categoryId`가 안정 카테고리 코드.
- 상품 URL: `/item?itemNo=<9자리>&storeType=HYPER` — `itemNo`가 안정 상품 코드 → `mart_native_code` 1순위.
- 익스프레스 경로: `/express` 별도 — `storeType=EXP`로 구분.
- **`/exhibit?gnbNo=...&promoNo=...&storeType=...`** 형태의 행사 URL은 사용자 지적대로 변동성 있는 표시용 URL — `gnbNo`/`promoNo`가 매주 바뀔 수 있으므로 **식별자로 쓰지 말 것**.
- **`<a href="/p/<slug>">` 같은 앱 라우팅용 내부 href**는 클릭 시 위 exhibit URL로 풀림. 캐노니컬 URL로는 `/p/<slug>` 자체가 더 안정적일 수 있음 (G1에서 클릭 시 최종 URL 비교 검증 필요).

## 외부업자 판별 (옵션 B — 플래그)
- 사이드바 분류:
  - 배송: **매직배송**(=홈플러스 자체) / **판매자택배**(=외부 입점)
  - 파트너: 에프앤에프커머스, 팜투맘, ... (외부 입점 파트너 목록)
- 결정: `delivery_type = "매직배송" → external_seller=false`, `"판매자택배" → true`.
  파트너명도 같이 저장(`seller_name`)해서 사용자 토글에 활용.

## 단위 환산가 — 사이트가 명확히 노출
- 패턴 1: **"10G당 200원"**, **"100g당 X원"**, **"100ml당 X원"**
- 패턴 2: **"1개당 14,990원"** (낱개 상품)
- 같은 정규식으로 이마트/홈플 둘 다 커버 가능: `(\d+)\s*(?:g|G|ml|ML|개)\s*당\s*([\d,]+)\s*원`.

## 카테고리 트리
- 최상위 카테고리는 메인 페이지 nav에서 `categoryId=1~27`로 일관된 ID. 31개 정도.
- 하위 카테고리도 같은 `/list` 패턴 + `categoryDepth` 증가.
- 사이드바에 하위 카테고리/필터가 모두 노출되므로 트리 스크레이프 단순.

## 동적 스크롤 / 페이지네이션
- 카테고리 8(델리/치킨/초밥) 페이지 진입 직후 233건 표시("233개의 상품")가 미리 카운트로 노출.
- 초기 로딩 시 상위 N건만 DOM에 있고 스크롤 시 추가 로딩 — Playwright로 카드 카운트 == 233 도달까지 스크롤 + 5회 연속 불변 조건 결합.
- "더 보기" 버튼 텍스트도 보임 → 클릭 트리거 가능.

## G1에서 해야 할 액션 (홈플러스 슬롯)
1. 카테고리 진입은 `/list?categoryDepth=0&categoryId=N` 패턴. `/express` 경로는 별도 함수로 분리.
2. 상품 카드에서 `itemNo`/`storeType` 추출, 상품 상세 페이지 진입은 선택적(리스트에서 가격·환산가·할인율·평점·배송종류 다 보임).
3. 사이드바 "매직배송/판매자택배" 분리 → `external_seller` 플래그.
4. 단위 환산가는 리스트 카드 텍스트("10G당 200원")에서 정규식 추출.
5. 동적 스크롤: 표시된 총 건수 == 수집 카드 수 도달 + 5회 연속 카운트 불변까지 스크롤. "더 보기" 버튼 있으면 클릭 트리거 우선.
6. 캐노니컬 URL은 `/item?itemNo=<>&storeType=<>` 풀 절대경로로 저장 (앱 라우팅용 `/p/<slug>` 아님).
